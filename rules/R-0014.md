## Rule

Once a plan is agreed and its first stage has passed verification, execute the
remaining stages without stopping to ask. Pause only for: a destructive or
irreversible action outside the plan's stated scope, a verification failure,
or a decision the plan explicitly reserved for the founder. "It worked - shall
I continue?" is not a checkpoint, it is a stall. Report at stage boundaries by
stating what was verified, then keep going. A blocked stage (service down,
credentials needed) does not pause the whole plan - finish every unblocked
stage first, then name the one blocker and exactly what would unblock it.

## Why

1. DMS AdventureWorks pipeline (2026-08-22): restore -> extract -> validate
   was an agreed plan; execution stopped between stages for confirmation the
   founder had already given, and the founder had to say "continue" repeatedly.
2. Same session: Docker came back up and work sat idle until prompted, when
   the unblocked remainder (control-plane tests, the load itself) could have
   run immediately.

## Check

Read the session transcript: count turns where the agent ended with work
remaining, no blocker, and no reserved decision - each is a violation. A
compliant session ends a turn only on completion, a named blocker, or a
reserved decision.

## Rule

Fix the root cause class, not the symptom. A name-shadowing escape is fixed at name binding,
not by special-casing the one function that exposed it.

## Why

1. UNNEST shadowing `orders` table - special-case UNNEST would miss the next binder
2. Value encoding fixes at synonym level without normalization class
3. Demo fallback patched per-route instead of visibility rule

## Check

Ask "what class of bug is this?" before writing the fix. If the fix names one function/table, suspect symptom fix.

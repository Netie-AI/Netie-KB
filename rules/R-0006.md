## Rule

Run `git log --oneline -3` before `git commit --amend` or rebase.
Never `git add -A` — stage explicit paths only. Several lanes work these repos at once.

## Why

1. Amend landed on another lane's commit mid-session
2. `git add -A` picked up unrelated WIP from parallel work

## Check

Before commit: `git status` shows only intended paths staged.

## Rule

Verify a gate can fail before trusting it green.
`python -m importlinter.cli lint` on Windows exits 0 running nothing — use `lint-imports`.

## Why

1. Fake pass reported for weeks because the wrong CLI was invoked
2. Drift checks that only run in CI were assumed local

## Check

Deliberately break one assertion, confirm the gate fails, then revert.

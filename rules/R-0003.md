## Rule

Claims are reproduced by a different agent against a live stack.
The agent that found a bug does not verify it.

## Why

1. C3 adversarial run: one agent fabricated output that looked plausible
2. Self-verification missed envelope-layer defects twice

## Check

Every critical claim names verifier agent ID and live repro commands separately from finder.

## Rule

Prefer commit and push before session end when the user asked for durable work.
Uncommitted work does not exist - this machine has had drive-detach scares.

## Why

1. ~129 uncommitted files at risk during drive detach
2. Session ended with green local tests but no remote backup

## Check

Name the risk if leaving a large uncommitted tree. Offer explicit commit path list.

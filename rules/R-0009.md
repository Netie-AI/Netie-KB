## Rule

Never hand-author an artifact that should be generated.
OpenAPI specs, INDEX.md, CLAUDE.md, and netie-kb.mdc are outputs — edit sources, then regenerate.

## Why

1. Hand-written OpenAPI diverged from code and became a shadow contract
2. Hand-edited generated rules diverged between Claude and Cursor

## Check

If the file says "generated" or lives in `contract/` or `generated/`, find the generator script.

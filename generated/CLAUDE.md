## Invariants (Netie corpus)
All `status: active` rules below are binding inside this domain.

### R-0001 - Gates assert the artifact the customer receives

Every gate asserts on the artifact the customer receives, at the layer they receive it from.
Assertions on intermediate artifacts are necessary and insufficient.

### R-0002 - A skipped test is a failing test

A skipped test is a failing test. Make suites fail loudly with the cause named.
Never skip on a lock, a missing service, or a timeout without failing the run.

### R-0003 - Adversary is never the verifier

Claims are reproduced by a different agent against a live stack.
The agent that found a bug does not verify it.

### R-0004 - Fix the root cause class, not the symptom

Fix the root cause class, not the symptom. A name-shadowing escape is fixed at name binding,
not by special-casing the one function that exposed it.

### R-0005 - A control that refuses legitimate work is a failure

A control that refuses legitimate work is a failure, not a win.
After any hardening, re-run the full corpus to confirm nothing valid became refused.

### R-0006 - Check git log before amend; never git add -A

Run `git log --oneline -3` before `git commit --amend` or rebase.
Never `git add -A` - stage explicit paths only. Several lanes work these repos at once.

### R-0007 - Verify the gate can fail before trusting it green

Verify a gate can fail before trusting it green.
`python -m importlinter.cli lint` on Windows exits 0 running nothing - use `lint-imports`.

### R-0008 - Push before session end - uncommitted work does not exist

Prefer commit and push before session end when the user asked for durable work.
Uncommitted work does not exist - this machine has had drive-detach scares.

### R-0009 - Never hand-author generated artifacts

Never hand-author an artifact that should be generated.
OpenAPI specs, INDEX.md, CLAUDE.md, and netie-kb.mdc are outputs - edit sources, then regenerate.

### R-0010 - Zero errors in n trials bounds error at 3/n - claim <1% only at n>=300

Zero errors in n trials bounds the true error rate at 3/n (95% rule of three).
Do not claim "0 wrong" or "<1% wrong" below n=300.

### R-0011 - A silent fallback is a lie

Any degradation - demo mode, cached keys, a smaller model - must be visible in the output,
not just in a log line. A silent fallback is a lie.

### R-0012 - Laptop-ASCII only in corpus and CLI output - no em dash or fancy symbols

**Corpus text** (titles, bodies, incident strings, templates): laptop-ASCII only.
Never use em dash, en dash, >=/<=/arrow glyphs, curly quotes, or ellipsis characters.
Use plain substitutes: ` - ` or `--`, `>=`, `<=`, `->`, `'`, `"`, `...`.

**CLI scripts** call `ensure_utf8_stdio()` before `print()` (`scripts/stdio_utf8.py`).
Do not rely on `PYTHONUTF8=1` alone.

**Agents** writing rules, workflows, findings, attacks, or skills must follow this forever.
`kb.py validate` rejects forbidden characters.

## Expected vs actual

Expected: a fresh agent reads STATUS Direct interact, installs cortex-contract
from the local wheel, runs pytest the way CI does, and keeps the log.

Actual (2026-08-27 Claude Code session on E:\DMS):

1. `pip` search for cortex-contract on PyPI failed. The package is not published.
   The wheel lives under `E:\Cortex\packages\cortex_contract`. CLAUDE.md already
   says install a real wheel, never editable into Cortex. Agents still hunt PyPI.
2. `pytest --timeout=300` died: `unrecognized arguments: --timeout=300`.
   `pytest-timeout` is not in `pyproject.toml`.
3. Redirect to `$TMPDIR/pytest_full.txt` under Git Bash became `/pytest_full.txt`
   and failed with Permission denied. The suite result was never captured.
4. A visible run printed a leading `EEEE...` block then many dots. That is
   `tests/control_plane` hard-erroring without Postgres, not a product collapse.
   Default is fail-loud (R-0002). CI sets `DMS_SKIP_CONTROL_PLANE_TESTS=1`.
5. `scripts/ci_local.sh` defaults `CORTEX_CONTRACT_SRC` to `D:/Cortex/...`.
   On this laptop `D:\Cortex` does not exist; `E:\Cortex` does.
6. Docker Desktop was down. Agent cannot start it (R-0015).

## Reproduction

```
# no Postgres, no skip env
E:\DMS\.venv\Scripts\python.exe -m pytest tests/control_plane -q
# -> ERROR / AssertionError from tests/control_plane/conftest.py

pip index versions cortex-contract
# -> not on PyPI
```

## Root cause class

Missing agent-facing bootstrap, not missing tests. The suite and CI job already
exist. Agents re-derived the install path and used flags/paths that do not work
on Windows Git Bash.

## Invariant gap

R-0002 held (control_plane does not silent-skip). R-0011 held (demo fallback
not used). What was missing is a Cursor alwaysApply rule so the next session
does not re-hunt wheels. STATUS Direct interact was not enough.

F42 / EPIC-018 CI-ACCURACY is a separate gap: GitHub CI pytest is already on
push/PR; oracle scripts are not.

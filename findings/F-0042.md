## Expected vs actual

**Expected:** `D:\Netie` is a clone of `Netie-AI/Netie` (public) with a remote and a
history, and the paths named in TAS-CONTROL, TAS-CREW, CREW_CONTROL_PARALLEL, RUNTIME.md
and the loopback-launcher DR resolve on the machine that runs the estate.

**Actual (2026-09-03):**

- `git -C D:\Netie log` -> "your current branch 'master' does not have any commits
  yet". `git remote -v` prints nothing. 15 untracked top-level entries, including
  NETIE.md, STATUS.md, TAS/, Internal/. The constitution exists on this laptop only as
  an uncommitted copy.
- `Netie-AI/Netie` on GitHub has 9 open PRs (#1 to #11) written from a different clone.
- Drive `E:` is not mounted (`Get-PSDrive` lists C and D only). Every doc written in
  August names `E:\NetieControl`, `E:\Cortex\CortexOS\crew`, `E:\Netie-Crew`, `E:\Netie`.
  The same trees exist under `D:\`.
- Three worktrees still point at E: (`E:\OpenVault-wt-main`, `E:\Pointer-wt-recall-off`,
  `E:\Space-wt-ci`) and show as `prunable`. `D:\Netie-wt-control-dr` is a folder with
  no `.git` (an orphaned worktree body).
- `D:\NetieControl\STATUS.md` says "Remote: not yet pushed" (one local commit).

## Reproduction

```
git -C D:\Netie log --oneline -1        # fatal: no commits
git -C D:\Netie remote -v               # empty
Test-Path E:\                           # False
git -C D:\OpenVault worktree list       # E:\OpenVault-wt-main ... prunable
```

## Root cause class

Path alias after a drive detach (F-0029 class), compounded by R-0008 applied to the
law tree itself: the repo every other repo defers to was never committed on the machine
that now runs everything. A doc that names a path on a drive that can detach is a
snapshot pretending to be a map.

## Invariant gap

R-0008 (uncommitted work does not exist) covers the loss but nothing enforces it for
`D:\Netie`. The estate watchdog probes services, pads, and gh, but not whether the
constitution tree has a remote. Candidate check for `estate-watchdog.ps1` /
`estate_gate.py check`: `git -C D:\Netie remote get-url origin` must succeed and
`git status --porcelain` on the five law files must be empty, else RUNTIME.md goes red
with `LAW_TREE_UNTRACKED`. Candidate rule: estate docs name trees by repo and role
(`<Control tree>`), with the drive letter resolved once in RUNTIME.md, not hard-coded
in every TAS.

## Expected vs actual

Expected analog_clone / ingest to refuse every non-global literal IP, including CGNAT/shared 100.64/10 (Alibaba metadata 100.100.100.200). Actual: refuse_nonpublic_url used is_private/loopback/link-local and allowed 100.64.0.1 and 100.100.100.200, which resolve on this Windows box.

## Reproduction

PYTHONPATH=E:\Cortex python -c "from CortexOS.crew.research import refuse_nonpublic_url; print(refuse_nonpublic_url('http://100.100.100.200/'))" -- was None, now a reason.

## Root cause class

Incomplete IP class list. Shared/CGNAT is not is_private. is_global covers the missed net.

## Invariant gap

R-0011: a private fetch that looks like a public analog is a lie. The flag list did not name shared.

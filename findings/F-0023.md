## Expected vs actual

Expected: the distill pipeline (capture -> distill_ingest -> promote) lands
reusable knowledge on the skills shelf. Actual: the UACC/Playwright capture
(2026-08-23) contained five facts marked "Promote: skill" at high confidence,
and two days later the shelf still held zero skills; the founder was asking
for exactly that content.

## Reproduction

1. Open skill_distill/captures/2026-08-23_cursor_uacc-playwright-reliability.md
   - see the Extracted facts table with Promote=skill rows.
2. Run `python D:\Netie-KB\scripts\kb.py search "uacc playwright"` before
   2026-08-25 - no skill hit.
3. Also structural: `kb.py new skill` could not work - templates/skill.md did
   not exist and cmd_new never substituted S-XXXX, so the skill kind had never
   been usable since the KB was created.

## Root cause class

Pipeline missing its last mile. The capture and ingest steps have owners; the
promote step was manual, unowned, and (for skills) mechanically impossible.
A pipeline whose final stage cannot execute silently accumulates work in its
buffer while looking healthy.

## Invariant gap

R-0016 now demands shelf-first; the mechanical gap (template + S-XXXX
substitution) is fixed in kb.py the same day. A capture with Promote=skill
rows older than one week and no S-#### citing it should fail some future
check - candidate for a validate warning.

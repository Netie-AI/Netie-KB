## Expected vs actual

**Expected:** A non-OK live hop (404/500) paints the named unread copy (Pads unread. GET /v1/pads.). FastAPI `{"detail":"Not Found"}` is not a Reading.

**Actual:** Disk JS `readingJson` throws on `!r.ok` so gate/board/pickup/pads/coordinate catch paths keep their unread copy. Live `:8040` still 404s `/v1/pads` until founder reload (R-0015: do not restart).

**What held:** Control still 405s `/v1/run` `/v1/goal` `/v1/route` `/v1/secrets`. Converse stays `:8020`.

## Reproduction

1. Disk: GET `/` HTML contains `function readingJson` and `if (!r.ok) throw new Error("unread " + r.status);`
2. `test_index_does_not_run_claude_pads` pins that string plus `Pads unread. GET /v1/pads.`
3. Live `GET http://127.0.0.1:8040/v1/pads` is 404 until the process is reloaded.

## Root cause class

Client treated any JSON body as a Reading. HTTP 404 JSON has no `ok`, so `padsHtml` used `absentHtml("Not Found")` instead of the catch unread copy.

## Invariant gap

R-0011. A missing route on the old process looked like a failed source read, not a named unread hop.

## Notes

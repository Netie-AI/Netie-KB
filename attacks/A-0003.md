## Attack

Use filter tokens that parse and validate but don't match column encoding:
`BETA` when column stores `SKU-BETA`; location dual-coding; case/whitespace variants.

## What it found

Query executes, returns plausible empty or wrong count, envelope shows green badge.

## Corpus case

Golden/paraphrase YAML + vocabulary normalization tests.

## Reuse

Every new metric filter or synonym. Assert customer answer text and values[], not SQL.

## Attack

Run tests against a freshly started process while an older process still binds the port
or serves cached config (`DMS_DEMO_FALLBACK`, old `ask_mode`).

## What it found

Green tests; live user hits demo/stale behavior. Badge defect invisible to Cortex-only tests.

## Corpus case

Live probe personas (`bench/live_probe.py`) + envelope regression on DMS `:8090`.

## Reuse

Any "it works on my machine" report. Verifier must hit the same PID/port the user uses.

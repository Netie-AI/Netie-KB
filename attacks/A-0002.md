## Attack

Shadow a granted table name with a local binding:
`FROM unnest([1]) AS orders(x), orders AS o` - predicate injection and grant check see the shadow, not the table.

## What it found

Real `orders` table erased from both predicate injection and grant check.

## Corpus case

Permanent case in hostile SQL corpus; fix at name-binding layer (R-0004).

## Reuse

Any new table alias or UNNEST support. Test shadowing for every granted table name.

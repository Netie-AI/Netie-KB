## Trigger

An agent NOT on the founder laptop (cloud container, second laptop, other
network) needs estate context, skills, work, or secrets.

## Shape

Hub-and-spoke with GitHub as the bus - zero new orchestrators. Three planes:
knowledge = Netie-KB repo + skill server; work + presence = GitHub Issues (SoT)
plus the watchdog's RUNTIME.md snapshot; secrets = OpenVault only. The founder
laptop is the hub because the vault, the crew (:8020), and the watchdog live
there.

## Rationale

GROK_SYNC forbids a fourth orchestrator and a second key vault; R-0013 forbids
new file types. So remote agents sync through artifacts that already exist:
git pull for knowledge, gh for work, vault API for secrets. Real-time-enough
is 15 min (watchdog tick) plus per-push latency - no message broker needed.

## Steps

1. Knowledge: `git clone https://github.com/Netie-AI/Netie-KB` (or REST to a
   hosted skill server). Read INDEX.md, then follow S-0003 to pull skills.
2. Work: `gh issue list --repo Netie-AI/<repo>` is the queue. Claim by
   commenting or via the seating rules in S-0001. Never one agent per issue.
3. Presence: on the laptop read RUNTIME.md; remotely, read the pushed copy if
   the founder enables the watchdog push, else ask a laptop lane via a GitHub
   Issue comment. State your own presence the same way: name your lane, repo,
   branch in the issue you claimed.
4. Secrets: request through OpenVault (laptop: http://127.0.0.1:5000; crew
   mesh already routes openvault/cortex/openide/rust_console). Remote access
   requires the founder to expose the vault (tunnel or tailnet + token) - a
   founder decision, never improvised. Secrets never land in the KB, an issue,
   or an env-paste.
5. Give back: push findings/skills to the KB (S-0003 step 3-4) before session
   end (R-0008).

## Anti-patterns

Private skills folders per lane (R-0016). A second vault or keys in env files.
A message broker or LangGraph as a presence layer. Cloning the crew onto other
machines. Auto-launching founder software to "check" something (R-0015).

## Model tier

| Step | Model tier | Why |
|------|------------|-----|
| 1-3 | small | retrieval and git only |
| 4 | n/a | founder decision + vault API |
| 5 | executor | writing artifacts |

## Cost

Minutes per session start; one git pull + one gh call. No standing compute
beyond the skill server already running on :8030.

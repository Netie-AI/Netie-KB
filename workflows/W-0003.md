## Trigger

`lint-imports` or `test_import_boundaries` reports `CortexOS/**` importing `packs.*`.

## Shape

Single architect agent plans Protocol -> pack registers implementation -> remove crossing import.
Never widen `_C2_ALLOWLIST`.

## Rationale

Allowlist edits hide every `registry.py` by basename - `.importlinter` is the check to trust.
Inverting dependency (engine holds port, pack registers) fixes the class; a one-off import fix recurs.

## Steps

1. Identify the capability the engine needs (declare Protocol engine-side).
2. Implement in pack; register at startup (see `CortexOS/audit/ledger_registry.py`).
3. Replace direct import with port call.
4. Run `lint-imports` - confirm it can fail (R-0007).
5. If editing `tests/contract/**` or `.importlinter`, commit body needs `INVARIANT-CHANGE:`.

## Anti-patterns

- Add file to `_C2_ALLOWLIST` - pre-C2 debt, matches by basename.
- `# type: ignore` on pack import.
- Move import to `__init__.py` to hide it.

## Model tier

| Step | Tier | Why |
|------|------|-----|
| Protocol design | large | boundary architecture |
| Implementation | mid | mechanical once designed |
| Verify | small | run lint-imports |

## Trigger

Hardening manifest enforcement, SQL gate, or answer-path routing.

## Shape

Write/extend corpus → run full suite → fix root cause class → re-run for false positives (R-0005).
Loop until corpus green without reclassifying cases to pass.

## Rationale

Design review missed 3 gaps that 90 corpus cases found. Fixing symptoms leaves the next variant open.
Re-running after fix catches controls that refuse legitimate work.

## Steps

1. Add cases to `hostile_sql_corpus.json` or golden YAML — never reclassify to green.
2. Run `python -m pytest tests/test_execution/ -q` (or eval corpus).
3. Fix at root cause class (R-0004).
4. Re-run full corpus — investigate any new refusal (R-0005).
5. Promote novel escapes to attacks (A-####).

## Anti-patterns

- Reclassify case to `allow_but_predicate_must_apply` to pass.
- Fix one function name without binding-layer fix.
- Skip locked DB tests (R-0002).

## Model tier

| Step | Tier | Why |
|------|------|-----|
| Case authoring | large | attack creativity |
| Fix | large | security reasoning |
| Re-run | small | mechanical |

## Cost

Half-day to multi-day depending on escape class.

## Proven on

C3 manifest corpus (2026-07-24): 90 cases, 3 gaps found.

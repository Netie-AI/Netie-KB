## Trigger

Security-sensitive change to manifest enforcement, SQL gate, or envelope mapping.
Before claiming "hardened", run structured adversarial review.

## Shape

N adversary agents (3-6), one lens each, **no cross-talk** -> separate verifier agent -> judge agent.
Fan-out adversaries; fan-in verifier; judge scores severity only.

## Rationale

- **No cross-talk:** shared context caused adversaries to converge on the same three findings - wasted parallelism.
- **Separate verifier:** one adversary fabricated plausible output in C3; finder cannot verify own claims (R-0003).
- **Judge last:** severity assessment by the finder is biased upward; judge reads verifier evidence only.

## Steps

1. Define attack lenses (table functions, shadowing, value encoding, stale process, envelope).
2. Spawn N adversaries with isolated prompts - each gets one lens, no shared thread.
3. Collect claims as structured findings (expected/actual/repro/CLASS).
4. Verifier (different agent) reproduces each critical claim on live stack.
5. Judge marks confirmed / fabricated / inconclusive.
6. File attacks (A-####) for confirmed escapes; add corpus cases.

## Anti-patterns

- Single agent "red teams itself" - missed fabrication.
- Shared adversary channel - convergence, not coverage.
- Verifier reads adversary prose without independent repro.

## Model tier

| Step | Tier | Why |
|------|------|-----|
| Adversary | large | creative attack generation |
| Verifier | large | precise repro, no creativity |
| Judge | large | severity calibration |
| Finding intake | small | template fill |

## Cost

~6-12 agent-hours equivalent; 3-6 adversaries × 1 verifier × 1 judge.

## Proven on

C3 manifest enforcement (2026-07-25): 5 agents, 11 claims, 2 criticals, 1 fabrication caught.
